# Neon Brutalist Format Website

## Structure

- `index.html` contains the standalone website flow.
- `styles.css` owns the visual grammar: acid background, dark surfaces, condensed type, hairline borders and modular grids.
- `script.js` only prevents form reload and gives light button feedback.

## Project Rule

Keep this website in its own folder. Do not mix it with the Nar Zeytin QR Menu project.
