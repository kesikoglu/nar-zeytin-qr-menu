# Neon Brutalist Format

This folder is a reusable visual format, not a fixed Nova Studio content page.

## Structure

- `index.html` contains replaceable content slots through `data-slot` sections.
- `styles.css` owns the visual grammar: acid background, dark windows, condensed type, hairline borders and modular grids.
- `script.js` only prevents form reload and gives light button feedback.

## Content Rule

Keep the format stable and replace only slot content, images and links per project. The standard website content from `STANDARD-CONTENT.md` is intentionally not mapped into this design.
